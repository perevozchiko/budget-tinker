# Contributing

BudgetTinker is an early desktop budgeting project. Discuss substantial changes with the
maintainer first. Include a concrete problem, expected behavior and synthetic reproduction.
Never attach personal budgets, bank credentials or proprietary application assets.

Use stable Rust supporting edition 2024. Run the four checks in AGENTS.md before submitting.
Financial changes should test integer amounts, atomic transfers, persistence and Undo/Redo.
Use fresh temporary budgets for demos; normal startup can open your recent budget.
Document new asset provenance in ATTRIBUTION.md. Keep changes focused and the UI in English.

Contributions to project-owned code and documentation are submitted under MIT OR Apache-2.0.
Contributors must have authority to submit their work and identify third-party code/assets
and their exact notices. No separate contributor agreement is claimed. See LICENSE-STATUS.md
and docs/PUBLIC-RELEASE-AUDIT.md for license scope and remaining platform checks.
Do not submit third-party code without its license and attribution.
